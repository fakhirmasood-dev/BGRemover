# FM-Mart
 <h2>About Project</h2>
<p>BGRemover is a full-stack web app built with django.It take images as input and return the processed the image with removed background.It also take images as URL input.
It has security features such as image validation,image size limitation and image dimension limitation.</p>

 <h2>Key Features</h2>
<ul>
    <li>Image Input</li>
    <li>Remove Background</li>
    <li>Image Input Using URL</li>
    <li>Image Authentication</li>
    <li>Responsive Design</li>
</ul><br>

<h2>
Installation
</h2>
<h3>Clone the repository</h3>
<p>git clone https://github.com/fakhirmasood-dev/BGRemover<br>
cd FM-Mart<p>

<h3>Create a Virtual environment</h3>
<p>python -m venv venv<br>
Activate it:
<p>
<h4>Windows</h4>
<p>venv\scripts\activate</p>
<h4>Linux/macOS</h4>
<p>source venv/bin/activate</p>
<h3>Install dependencies</h3>
<p>pip install -r requirements.txt</p>
<h3>Apply migrations</h3>
<p>python manage.py migrate</p>
<h3>Run the development server</h3>
<p>python manage.py runserver<br>
Open this url in browser http://127.0.0.1:8000/bgremover/home</p>
<h3>Environment Variables</h3>
<p>create .env file and provide all environment variables.</p>
